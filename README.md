
# Hero Section with AI Regeneration

A beautiful, interactive hero section component built with Next.js and Tailwind CSS. This project was created for the Vibe Coder Mini Challenge.


## Features

- **Modern Hero Section Design**
  - Clean, responsive layout
  - Professional typography
  - Visually appealing color scheme
  - Call-to-action button

- **Interactive Elements**
  - "Regenerate with AI" button that simulates AI content generation
  - Inline text editing for headline and subheadline
  - Visual feedback during regeneration
  - Smooth transitions between content changes

- **Responsive Design**
  - Adapts beautifully to all screen sizes
  - Mobile-first approach
  - Optimized layout for different devices
